# Latihan CSS — Hari 03

Folder ini berisi latihan HTML dan CSS dengan contoh halaman profil, formulir
pendaftaran, dan tabel jadwal. Beberapa halaman memakai stylesheet eksternal
untuk mempraktikkan layout responsif, komponen, serta styling form.

## Halaman

- [`index.html`](./index.html) — halaman Home dengan tautan ke halaman Tentang,
  situs lain, email, dan artikel.
- [`tentang.html`](./tentang.html) — halaman Tentang dengan tautan ke artikel.
- [`kontak.html`](./kontak.html) — informasi kontak melalui email.
- [`profil.html`](./profil.html) — halaman profil dengan bagian Tentang,
  Keahlian, Layanan, Galeri, dan Tautan Berguna. Halaman ini menggunakan
  `css/style.css`.
- [`daftar.html`](./daftar.html) — formulir pendaftaran yang menggunakan
  `css/style2.css`.
- [`jadwal.html`](./jadwal.html) — tabel jadwal pelatihan yang menggunakan
  `css/style.css`.
- [`blog/artikel-1.html`](./blog/artikel-1.html) — artikel pengantar tentang
  pengembangan web.

## Stylesheet dan Aset

- [`css/style.css`](./css/style.css) — gaya umum untuk tipografi, warna,
  navigasi, kartu layanan, galeri, form, dan tabel; mencakup aturan responsif.
- [`css/style2.css`](./css/style2.css) — gaya formulir pendaftaran, termasuk
  fieldset, input, tombol, dan tampilan layar kecil.
- `img/IMG_9586 merah 3r.jpg` — gambar profil pada halaman profil.
- `img/images.jpeg` — gambar-gambar pada galeri profil.

## Menjalankan

Buka berkas HTML yang ingin dilihat di browser. Untuk melihat contoh halaman
yang memakai CSS, buka `profil.html`, `daftar.html`, atau `jadwal.html`.
