# Portofolio Mufid Isnan Ardianto

Proyek portofolio pribadi untuk memperkenalkan profil, keahlian, galeri proyek,
estimasi harga layanan, dan informasi kontak Mufid Isnan Ardianto. Halaman
dibuat dengan HTML dan ditata menggunakan CSS responsif.

## Halaman

- `index.html` — halaman utama dengan bagian Beranda, Tentang Saya, Keahlian,
  Galeri Proyek, Harga dan Jadwal, serta Hubungi Saya.
- `tentang.html` — profil lengkap yang memuat pendidikan, minat, teknologi yang
  dipelajari, prinsip belajar, dan tautan ke formulir kontak.

Kedua halaman menggunakan stylesheet `css/style.css`.

## Aset

- `css/style.css` — mengatur layout, navigasi, hero, kartu keahlian, galeri,
  tabel harga, formulir kontak, footer, dan tampilan responsif untuk layar
  desktop maupun perangkat kecil.
- `img/profil.jpg` — foto profil yang digunakan pada halaman utama dan profil
  lengkap.
- `img/pict1.jpg` — gambar untuk galeri proyek pada halaman utama.

## Menjalankan Proyek

Buka `index.html` di browser. Gunakan tautan **Profil Lengkap** pada navigasi
untuk membuka `tentang.html`. Tidak diperlukan proses build atau instalasi
dependensi.
