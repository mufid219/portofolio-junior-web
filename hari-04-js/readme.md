# Program Pengolah Nilai Siswa (CLI Node.js)

Aplikasi berbasis terminal/CLI sederhana untuk mencatat nilai satu kelas, menghitung statistik, dan menampilkan predikat kelulusan siswa.

## Persyaratan Sistem
- Node.js versi 18.0.0 atau yang lebih baru (membutuhkan modul `readline/promises`).

## Cara Menjalankan Program

1. Simpan kode program ke dalam berkas bernama `index.js`.
2. Buka terminal/command prompt di direktori tempat berkas disimpan.
3. Jalankan perintah berikut:
   ```bash
   node latihan5.js
