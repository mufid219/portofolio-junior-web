# Latihan HTML — Hari 02

Folder ini berisi latihan dasar HTML dan halaman portofolio sederhana Mufid
Isnan Ardianto. Materi yang dipraktikkan mencakup struktur halaman, navigasi,
tautan, gambar, formulir, dan tabel.

## Halaman

- [`index.html`](./index.html) — halaman Home dengan ringkasan profil, navigasi,
  dan tautan ke artikel.
- [`tentang.html`](./tentang.html) — informasi singkat tentang profil dan
  keahlian.
- [`kontak.html`](./kontak.html) — halaman informasi kontak.
- [`profil.html`](./profil.html) — halaman profil, keahlian, dan tautan belajar.
- [`daftar.html`](./daftar.html) — contoh formulir pendaftaran.
- [`jadwal.html`](./jadwal.html) — contoh tabel jadwal pelatihan.
- [`blog/artikel-1.html`](./blog/artikel-1.html) — artikel latihan yang ditautkan
  dari halaman Home dan profil.

## Aset dan Proyek

- `img/profil.jpg` — gambar profil yang digunakan pada halaman.
- `css/style.css` — berkas CSS latihan.
- [`proyek-1-landing-page/`](./proyek-1-landing-page/) — proyek portofolio
  landing page tersendiri. Lihat
  [README proyek](./proyek-1-landing-page/README.md) untuk detailnya.

## Menjalankan

Buka `index.html` langsung di browser. Halaman-halaman latihan lainnya dapat
dibuka melalui berkas HTML masing-masing.
