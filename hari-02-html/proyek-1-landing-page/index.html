Membangun antarmuka web yang rapi dan API yang mudah dirawat.

Saya Mufid Isnan Ardianto, lulusan S1 Teknik Informatika Universitas Dian Nuswantoro yang berfokus pada web development. Saya senang mengubah kebutuhan pengguna menjadi aplikasi web yang jelas, terstruktur, dan nyaman digunakan.

Diskusikan Proyek Anda

Tentang Saya

Saya menempuh pendidikan S1 Teknik Informatika di Universitas Dian Nuswantoro. Selama kuliah saya banyak mengerjakan proyek berbasis web, mulai dari halaman statis sederhana hingga aplikasi full-stack dengan RESTful API dan basis data.

Minat utama saya adalah web development. Saya terbiasa memakai JavaScript, TypeScript, ReactJS, Redux, Tailwind CSS di sisi frontend, serta Node.js, Express.js, Golang, Java, dan Spring Boot di sisi backend. Untuk basis data, saya pernah menggunakan MongoDB, MySQL, PostgreSQL, dan OracleDB.

Saya juga menerapkan OOP, Clean Architecture, Git, Docker, dan Postman dalam proses pengembangan agar kode lebih mudah diuji dan dikembangkan. Baca profil lengkap saya.

Keahlian

Frontend Development

Membangun antarmuka web yang responsif dan terstruktur menggunakan HTML, CSS, serta library JavaScript modern.

  • HTML5 dan CSS3
  • JavaScript dan TypeScript
  • ReactJS, Redux, dan Tailwind CSS

Backend dan Basis Data

Mengembangkan layanan backend, mengelola basis data relasional maupun dokumen, serta menyusun query yang aman dan efisien.

  • Node.js, Express.js, Golang, dan SQLx
  • Java dan Spring Boot
  • MongoDB, MySQL, PostgreSQL, dan OracleDB

API dan Praktik Engineering

Merancang RESTful API yang konsisten, menerapkan pemisahan tanggung jawab, serta memakai alat bantu pengembangan dan pengujian.

  • RESTful API, Clean Architecture, dan OOP

  • Docker dan Postman
