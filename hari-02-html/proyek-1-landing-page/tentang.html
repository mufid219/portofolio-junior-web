Profil Lengkap

Halaman ini berisi ringkasan pendidikan, minat, dan perjalanan belajar saya di bidang web development.

Pendidikan

S1 Teknik Informatika

Universitas Dian Nuswantoro, Semarang.

Selama kuliah saya mempelajari dasar-dasar pemrograman, struktur data, basis data, rekayasa perangkat lunak, dan pengembangan aplikasi web. Sebagian besar tugas akhir dan proyek mata kuliah saya kerjakan dalam bentuk aplikasi web.

Minat

Minat utama saya adalah web development, khususnya membangun antarmuka yang rapi sekaligus API yang mudah dirawat.

  • Frontend development dengan ReactJS dan TypeScript
  • Backend development dengan Node.js, Golang, dan Spring Boot
  • Perancangan RESTful API dan penerapan Clean Architecture
  • Pengelolaan basis data relasional dan dokumen
