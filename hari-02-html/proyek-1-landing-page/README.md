# Portofolio Mufid Isnan Ardianto

Proyek halaman portofolio pribadi untuk memperkenalkan profil, keahlian, contoh
proyek, estimasi layanan, dan informasi kontak Mufid Isnan Ardianto. Halaman
dibuat menggunakan HTML.

## Halaman

- `index.html` — halaman utama dengan bagian Beranda, Tentang Saya, Keahlian,
  Galeri Proyek, Harga dan Jadwal, serta Hubungi Saya.
- `tentang.html` — profil lengkap yang memuat pendidikan, minat, teknologi yang
  dipelajari, prinsip belajar, dan tautan kontak.

## Aset

- `img/profil.jpg` — foto profil yang digunakan pada halaman utama dan profil
  lengkap.
- `img/pict1.jpg` — gambar yang digunakan untuk galeri proyek pada halaman utama.

## Menjalankan Proyek

Buka `index.html` di browser. Navigasi utama mengarah ke bagian-bagian pada
halaman tersebut, sedangkan tautan **Profil Lengkap** membuka `tentang.html`.
